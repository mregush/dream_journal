# Дневник сна в Telegram

Бот: [@dream_journal_agent](https://t.me/dream_journal_agent).

Java 21, Spring Boot, PostgreSQL, Flyway и TelegramBots. Получение событий — long polling;
для локального запуска не нужны домен и публичный HTTPS-адрес.

## Что реализовано

- `/start`: регистрация пользователя и приветствие. Повторный вызов обновляет данные
  Telegram, сохраняя существующие настройки и дату регистрации.
- `/help`: доступные команды. Список команд автоматически устанавливается в меню Telegram.
- Обработка только личных текстовых сообщений; сообщения из групп игнорируются.
- PostgreSQL и миграция `V1__create_bot_users.sql`.
- Проверка обязательного токена при включённом Telegram. Токен не включается в сообщения
  об ошибках приложения; логи библиотеки Telegram отключены, поскольку могут содержать URL с токеном.
- Модульные тесты команд и интеграционные тесты с настоящим PostgreSQL через Testcontainers.

Опрос, календарь, статистика и отправка напоминаний будут следующими этапами.
Часовой пояс и время опроса пока не задаются, напоминания по умолчанию выключены.

## Требования

- JDK 21.
- Docker с Docker Compose v2; Docker должен быть запущен.
- Токен от [@BotFather](https://t.me/BotFather).

Используется Gradle Wrapper: отдельно устанавливать Gradle не нужно.

## Запуск в IntelliJ IDEA

1. Открыть проект как Gradle-проект, дождаться загрузки зависимостей.
2. Для Project SDK и Gradle JVM выбрать JDK 21.
3. Запустить базу из терминала проекта:

   ```shell
   docker compose up -d --wait postgres
   ```

4. Создать конфигурацию запуска для `ru.dreamjournal.DreamJournalApplication`.
5. В **Environment variables** добавить `TELEGRAM_BOT_TOKEN` со значением из BotFather.
   Имя бота уже задано как `dream_journal_agent`.
6. Запустить приложение, открыть бота и отправить `/start`, затем `/help`.

При успешном подключении появится лог `Telegram bot @dream_journal_agent started with long polling`.
Для проверки сохранения профиля:

```shell
docker compose exec postgres psql -U dream_journal -d dream_journal -c \
  'SELECT telegram_user_id, username, created_at FROM bot_users;'
```

Одновременно должен работать только один экземпляр приложения с одним токеном.
Пока приложение запущено на компьютере, бот доступен; после остановки приложения ответы прекращаются.

## Запуск из терминала

Указать `TELEGRAM_BOT_TOKEN` в окружении текущего терминала. Для zsh можно ввести его скрыто,
не записывая значение в историю команд:

```shell
read -rs 'TELEGRAM_BOT_TOKEN?Токен бота: '
export TELEGRAM_BOT_TOKEN
printf '\n'
docker compose up -d --wait postgres
./gradlew bootRun
```

`.env.example` содержит перечень настроек. Файл `.env` исключён из Git.
**Spring Boot не загружает `.env` автоматически**: переменные для приложения нужно задать в IntelliJ
или экспортировать в терминале. Docker Compose читает `.env` самостоятельно.
Если изменить параметры базы в `.env`, те же значения нужно передать приложению.

## Конфигурация

| Переменная | По умолчанию | Назначение |
|---|---|---|
| `TELEGRAM_BOT_TOKEN` | — | Обязательна при включённом Telegram |
| `TELEGRAM_BOT_USERNAME` | `dream_journal_agent` | Username без `@` |
| `TELEGRAM_BOT_ENABLED` | `true` | `false` для запуска без подключения к Telegram |
| `DB_NAME` | `dream_journal` | Имя локальной базы |
| `DB_PORT` | `5432` | Локальный порт PostgreSQL |
| `DB_USERNAME` | `dream_journal` | Пользователь PostgreSQL |
| `DB_PASSWORD` | `dream_journal_local` | Пароль для локальной разработки |
| `DB_URL` | `jdbc:postgresql://localhost:5432/dream_journal` | Полный JDBC URL; переопределяет адрес, порт и имя базы |

Для внешнего PostgreSQL задать `DB_URL`, `DB_USERNAME` и `DB_PASSWORD`.
Локальная база доступна только на `127.0.0.1`; данные сохраняются в Docker volume `postgres_data`.
Для сервера нужно задать отдельный пароль. Изменение `POSTGRES_PASSWORD` не меняет пароль
в уже инициализированном volume.

## Проверки и сборка

```shell
./gradlew test
./gradlew bootJar
```

Интеграционные тесты сами поднимают отдельный временный PostgreSQL и не используют локальную базу.
Docker обязателен; токен и доступ к Telegram для тестов не нужны.
Если Docker недоступен, только модульные тесты можно выполнить отдельно:

```shell
./gradlew test --tests 'ru.dreamjournal.telegram.*'
```

Исполняемый jar: `build/libs/dream_journal-0.1.0-SNAPSHOT.jar`.

## Структура

- `ru.dreamjournal.telegram` — конфигурация подключения, маршрутизация сообщений, ответы Telegram.
- `ru.dreamjournal.user` — регистрация и сохранение профилей, независимо от Telegram DTO.
- `src/main/resources/db/migration` — версионируемые миграции Flyway.

Изменения схемы добавляются новой миграцией; применённые миграции не редактируются.

## Согласованная анкета для следующего этапа

Одна запись относится к местной дате пробуждения.

1. Качество сна: 1–10.
2. Длительность сна: часы и минуты.
3. Ночные пробуждения: 0–10.
4. Состояние перед сном: расслабленное, напряжённое, стресс, усталость; несколько вариантов.
5. Занятия перед сном: свободный ввод.
6. Ощущение отдыха утром: 1–10.
7. Комментарий: свободный ввод.

Далее: черновики и редактирование, календарь с выбором даты, месячная статистика,
настройки часового пояса и времени, ежедневные напоминания, размещение на VPS.
